# Odin Recipes

## Description
This is a basic recipe website built as part of The Odin Project's Foundation course. The goal of this project was to practice essential HTML skills before moving on to styling with CSS. 

The site includes:
* A main index page with links to various recipes.
* Individual recipe pages featuring images, descriptions, ingredients, and preparation steps.

## Skills Demonstrated
* Structuring documents with **HTML5**.
* Working with **Boilerplate** code (`<!DOCTYPE html>`, `<html>`, `<body>`, etc.).
* Creating links using **anchor tags** (`<a>`).
* Displaying images with **img tags**.
* Organizing content using **Unordered (`<ul>`)** and **Ordered (`<ol>`)** lists.
* Managing project files and folders within a Git repository.

## How to View
To view this project locally:
1. Clone the repository: `git clone [Your-Repo-Link-Here]`
2. Open `index.html` in your preferred web browser.
